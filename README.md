# Professional Personal Branding Poster Generator

## Project Summary

A production-ready template for generating hyper-realistic, executive-level personal branding posters suitable for LinkedIn, speaking engagements, and corporate marketing. This prompt produces high-end editorial photography with clean typography, minimal design elements, and professional positioning. Optimised for Gemini and similar image generators.

---

## Pre-Generation Checklist

- [ ] **Subject Name:** Defined and ready to use  
- [ ] **Photo References:** 2-3 headshots and body shots collected  
- [ ] **Job Title/Positioning:** Single clear positioning statement selected  
- [ ] **Tagline:** 3-line single statement written (no repetition)  
- [ ] **Supporting Pillars:** 3-5 credentials/keywords identified (horizontal list)  
- [ ] **Call-to-Action Quote:** Relevant one-liner in quotation marks  
- [ ] **Accent Colour:** Brand colour selected (e.g., burnt orange, teal, navy)  
- [ ] **Key Credentials:** Certifications, degrees, languages identified  
- [ ] **Image Generator:** Platform selected (Gemini, DALL-E 3, Firefly, etc.)  
- [ ] **Output Format:** 4K resolution confirmed

## Usage Instructions

1. **Fill placeholders** with subject-specific information using the reference guide above  
2. **Copy entire prompt** to your image generator (Gemini, DALL-E 3, Adobe Firefly)  
3. **Paste subject photos** as reference images in the generator  
4. **Generate** 2-4 variations and select the strongest output  
5. **Optional:** Fine-tune in Photoshop/Figma for logo placement or text refinement

## Key Design Principles

### Photography Style

- **Lighting:** Studio lighting with dramatic shadows on facial features  
- **Background:** Clean white, minimal distractions  
- **Composition:** Full-body, figure centre/left with side profile element at 20% opacity  
- **Retouching:** High-end commercial grade, sharp focus across frame

### Typography Strategy

- **Avoid Repetition:** Each text element serves a distinct purpose  
- **Line Breaks:** New sentence \= new line for readability  
- **Hierarchy:** Name (largest) → Title → Tagline → Credentials → Call-to-action

### Colour & Accents

- **Single Accent Colour:** Use brand colour consistently (geometric lines, icons, signature)  
- **Minimal Graphics:** Thin lines and 3 thematic icons only  
- **Burnt Orange Example:** Works well for operations, systems, energy positioning  
- **Teal/Navy:** Alternative for tech, data, leadership positioning

## Troubleshooting

### Issue: Text appears repetitive in output

**Solution:** Ensure tagline and bottom quote are meaningfully different. Test with distinct concepts in each.

### Issue: Background face is too prominent

**Solution:** Specify 20% opacity in composition. Some generators interpret "subtle" as 30-40%; be explicit.

### Issue: Accent colour doesn't render consistently

**Solution:** Name colour specifically (e.g., "burnt orange" rather than "orange"). Test with hex value reference if possible.

### Issue: Typography rendering is poor

**Solution:** Use Gemini or DALL-E 3, both stronger on text rendering. Avoid fancy fonts; stick with sans-serif.

### Issue: Figure looks awkward in suit

**Solution:** Specify "standing confidently, relaxed posture, one hand in pocket" to avoid stiff appearance.
